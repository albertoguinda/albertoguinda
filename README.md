### 🧠 About me

Full-Stack developer specialized in the convergence of **Web, IoT and AI**.
I build complex systems: Digital Twins, BIM viewers, industrial IoT integrations and AI-powered SaaS products.

Not a standard web dev — my approach is technical-scientific, focused on solving hard infrastructure and data problems.

- 🏗️ Currently building a **BIM viewer with IoT sensor integration** for infrastructure monitoring (dams, bridges, tunnels) using Three.js + React + TypeScript
- 🤖 Working on **AI-enhanced developer tools** and B2B SaaS products
- 📡 Background in industrial IoT (ESP32, MQTT, CoAP), computer vision and vector embeddings
